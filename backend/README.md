# ⚙️ TuneIt Backend & Sequencing Engines

This folder contains the core TypeScript sequencing engines for TuneIt:
- **`src/utils/driftAlgorithm.ts`**: Mental Drift Engine (Continuous Focus & Low-Friction Flow)
- **`src/utils/frameAlgorithm.ts`**: Frame Engine (3-Act Cinematic Narrative Arc)

---

## ⚡ Quick Benchmark Commands

Run these commands from inside the `backend/` directory:

```bash
# 1. Run Frame Engine Benchmark (3-Act Cinematic Mode)
npm run evaluate:frame

# 2. Run Mental Drift Engine Benchmark (Focus Mode)
npm run evaluate:musav

# 3. Run High-Scale MTG-Jamendo Benchmark (1,000 tracks test)
npm run evaluate:jamendo
```

For full setup instructions, see the main [Root README.md](../README.md).
