# Styles Directory

This folder is reserved for global styles, custom utility CSS classes, or third-party stylesheets that are not fully managed by Tailwind CSS.

- Tailwind CSS is imported and configured in [globals.css](file:///d:/WorkSpace/Projects/TuneIt/src/app/globals.css).
- Any modular stylesheets or global custom overrides can be placed here and imported into the root layout.
